# 008 — Les erreurs des débutants

Les joueurs qui découvrent la Larsen commettent souvent les mêmes erreurs.

---

# Jouer uniquement le fou

Certains joueurs cherchent uniquement à exploiter la grande diagonale.

Ils oublient complètement le développement.

Une attaque sans développement échoue presque toujours.

---

# Retarder le roque

Vouloir lancer une attaque avant d'avoir mis son roi à l'abri est très dangereux.

---

# Ouvrir la diagonale trop tôt

Il faut préparer l'ouverture du jeu.

Forcer les échanges sans développement donne souvent un avantage aux Noirs.

---

# Sous-estimer le centre

Même si la Larsen est hypermoderne, le centre reste essentiel.

Le laisser entièrement à l'adversaire conduit souvent à une position difficile.

---

# À retenir

✔ Développez toutes vos pièces.

✔ Roquez tôt.

✔ Contrôlez le centre.

✔ Ne jouez pas uniquement autour du fou b2.
