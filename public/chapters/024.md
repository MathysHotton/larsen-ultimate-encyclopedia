# 024 — Lire un PGN

Le format PGN est le standard mondial pour enregistrer les parties d'échecs.

Toutes les variantes de cette encyclopédie utilisent ce format.

---

# Que contient un PGN ?

- les informations de la partie ;
- les coups ;
- les commentaires ;
- les variantes.

---

# Pourquoi apprendre le PGN ?

Comprendre un PGN permet :

- d'échanger des parties ;
- d'utiliser les logiciels d'analyse ;
- de créer son propre répertoire.

---

## 💡 Conseil du GM

Prenez l'habitude de lire les commentaires entre les coups.

Ils sont souvent plus importants que les coups eux-mêmes.

---

## ✅ À retenir

Le PGN est la langue universelle des logiciels d'échecs.
