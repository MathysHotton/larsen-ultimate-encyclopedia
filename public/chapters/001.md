# 001 — Comment utiliser cette encyclopédie

Cette encyclopédie n'est pas un simple répertoire de variantes.

Son objectif est de vous apprendre **à comprendre les positions**, et non à mémoriser des suites de coups.

## Comment progresser ?

Nous vous recommandons de suivre les chapitres dans l'ordre.

Chaque nouveau chapitre repose sur les notions vues précédemment.

## Chaque chapitre contient

- une introduction ;
- les idées principales ;
- les variantes importantes ;
- les plans typiques ;
- les erreurs fréquentes ;
- un résumé.

## Conseil

Prenez le temps de rejouer les variantes sur l'échiquier.

Comprendre une idée vaut toujours mieux que mémoriser vingt coups.
