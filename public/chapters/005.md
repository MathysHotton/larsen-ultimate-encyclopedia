# 005 — Les objectifs de la Larsen

Lorsque vous jouez 1.b3, vos objectifs sont simples :

- développer rapidement le fou b2 ;
- contrôler les grandes diagonales ;
- préparer le petit roque ;
- exercer une pression constante sur le centre.

La Larsen n'est pas une ouverture tactique immédiate.

Elle construit progressivement une position solide avant de lancer les opérations.
