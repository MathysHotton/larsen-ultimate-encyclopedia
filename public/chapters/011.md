# 011 — Le contrôle du centre

L'une des idées fondamentales de la Larsen est de contrôler le centre sans l'occuper immédiatement avec les pions.

Contrairement aux ouvertures classiques comme 1.e4 ou 1.d4, les Blancs laissent souvent les Noirs avancer leurs pions centraux avant de les attaquer.

---

## Le centre

Les quatre cases centrales sont :

- e4
- d4
- e5
- d5

Contrôler ces cases permet :

- de développer plus facilement les pièces ;
- de disposer de davantage d'espace ;
- de préparer des attaques.

---

## L'approche hypermoderne

Après :

1.b3

les Blancs prévoient :

- Bb2
- e3
- Nf3

Le fou exerce alors une pression sur e5 depuis la grande diagonale.

Les Noirs peuvent sembler posséder davantage d'espace, mais ce centre devient une cible.

---

## L'objectif

L'objectif n'est pas de laisser les Noirs jouer librement.

Il s'agit de les encourager à construire un centre que les Blancs attaqueront ensuite.

---

## À retenir

✔ Le centre reste primordial.

✔ La Larsen le contrôle avec les pièces.

✔ Le fou b2 joue un rôle essentiel dans cette stratégie.
