# Comment travailler un chapitre ?

Pour progresser efficacement :

1. Lisez les explications.
2. Rejouez la variante sur l'échiquier.
3. Essayez de comprendre les idées.
4. Jouez quelques parties avec cette ligne.
5. Revenez consulter le chapitre après vos parties.

Cette méthode est beaucoup plus efficace que la simple mémorisation.
