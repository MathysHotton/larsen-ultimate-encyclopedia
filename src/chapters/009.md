# 009 — Avant de commencer le répertoire

Vous connaissez désormais les bases de l'ouverture Larsen.

Avant d'étudier les variantes, gardez toujours en mémoire les idées suivantes.

---

# Les variantes ne sont pas une fin

Le but n'est pas de mémoriser vingt coups.

Le but est de comprendre pourquoi chaque coup est joué.

---

# Les plans sont plus importants

Dans une même position, plusieurs bons coups existent.

Celui qui comprend les plans trouvera souvent le bon coup sans l'avoir appris.

---

# Jouez vos propres parties

Après chaque chapitre :

- jouez quelques parties ;
- analysez-les ;
- comparez-les avec l'encyclopédie.

C'est ainsi que les idées deviennent naturelles.

---

# Vous êtes prêt

Les chapitres suivants entreront dans le cœur du répertoire.

Chaque réponse noire sera étudiée en profondeur.

Bonne étude !
