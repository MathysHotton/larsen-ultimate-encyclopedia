Pourquoi cette encyclopédie ?

Larsen Ultimate Encyclopedia est un projet entièrement consacré à l'ouverture 1.b3. Son objectif est de regrouper les variantes, les idées stratégiques, les pièges tactiques, les statistiques et les analyses dans une seule application moderne.
